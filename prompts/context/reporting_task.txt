## Behavior
- Never edit `canban.sqlite` or move/archive the Card directly; keep temp/report files under `$CANBAN_RUN_DIR`.
- For code tasks, commit deliverables on the Card branch (no push) before reporting `completed`.

## Commands
- Report outcome: `"$CANBAN_CLI" report --state <completed|backlog|blocked|failed|working> --message 'Concise summary' [--file "$CANBAN_RUN_DIR/report.md"]`
  - `completed`: finished; `backlog`: already done/obsolete/not actionable (returns to Backlog); `blocked`: needs decision (`working`: interim progress; `failed`: error).
