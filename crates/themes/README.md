# Built-in themes

A pure data crate shared by AppServer preference validation and UI Kit. It has no NSH, persistence or product-domain dependencies. `canban` is the original default dark Canban palette. The other 16 palettes preserve the Terminal background, foreground, cursor and ANSI 16 values from the pinned sources below. App chrome derives accessible semantic surfaces and accents from those colors; it does not change the original Terminal ANSI values.

Classic palette source: [iTerm2-Color-Schemes](https://github.com/mbadolato/iTerm2-Color-Schemes), revision `5fad1bde2d00c4eb9cb9264599ebb3d981eca4f0`. Display names omit mode labels; all selected source variants are dark.
