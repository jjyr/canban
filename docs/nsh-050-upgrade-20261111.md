# NSH 0.5.0 upgrade, 2026-11-11

## Dependency and compatibility changes

All three direct dependencies (`nsh-core`, `nsh-base`, and
`nsh-platform-macos`) move together from NSH 0.4.0 at
`aca7b8f92a33af9d83c3693a516f649f7ea5c5e5` to the official
[`v0.5.0` release](https://github.com/longbridge/nsh/releases/tag/v0.5.0),
commit `f4d68f7f9f31eb7b3ecc8a4cbc31096d5c6238a1`.
The full commit remains pinned in `Cargo.toml`; `Cargo.lock` resolves the NSH
packages to one 0.5.0 source and records the required transitive changes.
The existing mise toolchain and explicit highlighting feature remain unchanged.

The release replaces the desktop window API. The initial workspace check
identified removed `desktop::set_title` / `set_title_bar` calls; compiling the
Gallery also identified its removed `order_front` call. The adaptation uses the
new `WindowRef` API:

- Capture `current_window()` during render and update `WindowAttributes.title`
  through that handle in the Board/Terminal title effects. Event callbacks and
  effects do not rediscover a window from ambient render context.
- Share the custom hidden 42-point title bar through
  `ui/frame.rs::configure_window_chrome`, used by production and the existing
  Gallery chrome fixtures. The new non-exhaustive attribute structs are created
  with `Default` and assigned only the required fields.
- Capture the Gallery reminder fixture's window and use `WindowRef::focus()`
  for its explicit Focus window action.

No workflow, persistence/schema, update installation or runtime ownership
behavior is changed by this upgrade. The separate native terminal component
continues using the same macOS registration interface.
